# Beyond the Honey Jar

FIT3179 Data Visualisation 2 GitHub Pages project.

## Publish
1. Upload every file/folder in this project to the root of a GitHub repository.
2. GitHub → Settings → Pages.
3. Deploy from a branch → `main` → `/ (root)` → Save.
4. Open the GitHub Pages URL after deployment.

Do not rename the `visualisations` folder unless you also update `script.js`.
